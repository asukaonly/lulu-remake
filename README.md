# 路路解密重制版

本项目的内容来源于《路路解密破解游戏(离线版).chm》中的「路路解密破解游戏第一部（技术）」。原游戏由路路及相关题目贡献者制作，原站域名为 `www.666666666666.com`。

这是一个非官方的网页重制版本，使用 React、TypeScript 和 Vite，方便在现在的浏览器里继续玩。题目和附件从离线版中整理，原有二进制附件直接复用；答案校验和提示根据保留下来的题目、脚本及附件分析重新实现。

目前保留 40 道可验证、需要解谜的题目，移除了无法恢复答案以及题面直接给出答案的关卡。支持本地保存答题状态和笔记，答对后目录显示 ✅。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
npm install
npm run dev
```

打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。运行 `npm run build` 可生成静态网页。

原始附件和整理后的关卡数据已包含在仓库中，启动游戏不需要 CHM 文件。更多说明见 [开发文档](docs/development.md)，来源检索记录见 [资料来源](docs/research-sources.md)。
