# 路路解密 · 开发说明

把 `路路解密破解游戏(离线版).chm` 中的「路路解密破解游戏第一部（技术）」迁移到现代浏览器。使用 React、TypeScript 和 Vite；关卡及原始附件均在本地，不依赖原站服务。

## 开始运行

需要 Node.js 22.12 或更新版本。

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5173 。安装时会把 Ruffle 复制到本地静态目录。首次安装需要联网；安装后运行游戏不需要外部网络。

```powershell
npm test          # 关卡、答案、资源完整性、存档和路由检查
npm run build    # 类型检查与生产构建
npm run preview  # 在本地预览 dist，默认 4173 端口
```

## 本次迁移

- 游戏保留 40 个需要解谜、且已有可靠答案或校验算法的关卡；34 个未恢复答案的关卡，以及 25 个题面直接给出答案的关卡已从界面和导航移除。界面连续编号为 1～40，目录、题目标题和提示弹窗使用同一编号。
- 左侧未解答关卡显示数字，答对后替换为 ✅，刷新后保留。悬停和屏幕阅读器仍能读到对应的顺序编号；旧版「自行完成」不会显示为已验证。
- 99 关的原始题面和源码仍保存在归档数据中，便于后续研究；游戏不展示源码面板。
- 45 个独立附件共 1,894,160 字节，逐字节复用并记录 SHA-256。
- 前几关的脚本线索整理成可直接阅读的题面；第 1 关通过「打开题目页」进入独立静态 HTML，源文件只有二十来行且不加载框架脚本。「查看网页源代码」或「检查」都能找到注释线索，答案回到游戏提交。
- 第 8、9 关（原始第 12、14 关）的 SWF 使用本地 Ruffle 播放，无须 Flash 插件。其他 EXE/RAR 等保持下载使用。
- 每关都有独立撰写的提示，点击「查看提示」后必须确认才显示；切换关卡后重新确认。笔记、答案及已解答状态自动保存到本机。
- 简洁双栏布局，手机可折叠数字目录。URL与存档继续使用原始ID，以兼容已有链接、完成状态和笔记；例如 `/#/level/14` 对应现在的第9关。已移除关卡的旧链接会跳到下一可用关卡，超出末关时返回最后一关。

## 答案验证的边界

CHM 中的 `Script129e.js` 原本向 `Password.php` 提交答案，但 CHM 没有包含 PHP 服务端或数据库。本项目不会伪造全部关卡的官方判定。

- 归档中共有 65 关恢复了本地校验，其中 40 关进入游戏，其余 25 关因题面直接给出答案而移除。此前逐个分析了 46 个待恢复关卡，新增恢复 32 关；完整推导、答案及其余 14 关的阻碍见 [逐关拆解记录](level-analysis.md)（含剧透）。
- 确定答案使用本地 SHA-256 对照校验。原有规则见 `scripts/import-chm.mjs`，附件恢复结果及证据见 `scripts/recovered-answers.json`；重新导入会保留这些结果。
- 原始第 79、91、93、94 关复现附件中的校验算法，允许多组正确解，不只匹配一个示例。原始第 94 关按原文提交十进制 ASCII 拼接串。
- 原始第 44 关按标准运算优先级使用 BigInt 计算。
- 未恢复关卡不再提供「自主练习」或手动标记入口；旧存档中的研究笔记仍保留，不计入当前目录。
- 这些校验用于单机练习。前端数据和存档可被玩家查看、修改，不提供联网排行榜或防作弊能力。

原始标题、原始页面文件名及题目代码保存在数据中。未迁移原站的排行榜、聊天、账号、金币和其他游戏章节。

## 文件结构

```text
src/App.tsx                 界面、导航、关卡交互
src/FlashPlayer.tsx         按需加载本地 Ruffle
src/styles.css             响应式样式
src/lib/progress.mjs        存档清理、路由和答案验证
src/lib/catalog.mjs         可玩关卡筛选与缺号路由
src/data/levels.json        99 关归档数据（游戏展示其中 40 关）
src/data/manifest.json      资源清单与校验信息
public/original/            原始附件（未修改）
public/puzzles/             独立题目页（线索保留在原始 HTML 响应中）
public/ruffle/              安装后生成的本地播放器（Git 忽略）
scripts/import-chm.mjs     CHM 提取与数据生成
scripts/level-copy.json    逐关提示、必要的题面适配及直接给答案的关卡排除标记
scripts/copy-ruffle.mjs    播放器复制脚本
tests/game.test.mjs        有效性与完整性测试
.archive/chm/              CHM 解包缓存（Git 忽略）
```

`public/original` 和 `src/data` 已生成并随项目保留，正常开发无须重复解包。

原始 CHM 不随仓库发布。如需重新导入，准备 `路路解密破解游戏(离线版).chm` 并放到项目根目录，安装 7-Zip 后运行：

```powershell
npm run import:chm
# 可选：指定另一个 CHM 路径
npm run import:chm -- "D:\path\路路解密破解游戏(离线版).chm"
```

Windows 默认寻找 `C:\Program Files\7-Zip\7z.exe`，其他系统寻找 `7z`；可通过 `SEVEN_ZIP` 环境变量指定路径。脚本会复用已有 `.archive/chm` 缓存；更换输入 CHM 前请移走该缓存目录。导入后再运行测试和构建。

## 保存与部署

答案和笔记存储在浏览器 `localStorage` 的 `lulu-remake-progress-v1` 中，兼容此前版本的存档。它按域名与端口隔离：`localhost` 与 `127.0.0.1` 的记录不同。当前精简界面不提供进度面板或导入导出入口。

生产输出为 `dist/`，可用任意静态 HTTP 服务放在网站根目录。使用 localhost 或 HTTPS 以支持 Web Crypto；服务应正确返回 WASM 的 `application/wasm` 类型。运行时不请求第三方字体、CDN 或原站 PHP 接口。

原始 EXE 属于旧版 Windows 练习程序，浏览器不会执行它们。个别原题明确涉及注册表、关闭调试器或重启行为，研究这些附件时适合使用隔离的旧系统测试环境。

原游戏内容及附件归原作者和贡献者所有，本项目保留来源用于本地复刻。Ruffle 等依赖的许可随安装包保留。
