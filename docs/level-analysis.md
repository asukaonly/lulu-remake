## 第 96 关 · 编码后的注册码

**状态：算法已还原，指定识别码缺失。**

16 个注册码字符与循环识别码相减：ASCII≤90 时减偏移16，否则减26。得到16个正数，要求互异，并要求4×4矩阵各行、各列、两条对角线的乘积相等。乘积采用原生32位整数。网页还要求把注册码各字符转十进制 ASCII 后拼接提交。

CHM 题面“识别码填写：”后为空。没有依据替它填入其他关的识别码，因此不能恢复这道原题的唯一输入条件。

原附件：`1309445920.rar`。

## 第 97 关 · 最后的挑战 · I

**状态：已追到 VB6 数学核心，尚无可靠输出。**

固定识别码为 `7263966326`。0x402fxx–0x4037xx 的原生函数从字符串位置1、3、5、7提取两位块，随后使用平方、按位 OR、模2，以及常数2010和365生成大数；最终还有浮点计算。

需要同时核实调用者传入的原始字符串和 VB6 Variant/Double 的转换及输出格式。避免用一般整数计算替代 VB6 语义而给出貌似正确的长数字。

原附件：`1309446426.rar`。
